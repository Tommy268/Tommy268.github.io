工具箱

小工具

几个平时会用到的小东西。全部在浏览器本地计算，输入的内容不会发到任何服务器。

JSON 格式化

粘贴 JSON，格式化、压缩或校验。报错会指出出错的位置。

时间戳转换

支持秒和毫秒（自动判断）。也可以把日期反向转成时间戳。

日期 → 时间戳

Base64 / URL 编解码

Base64 用 UTF-8 处理，中文不会乱码。

随机密码生成

用浏览器自带的加密随机数（crypto.getRandomValues），不是 Math.random。

SHA-256

用 Web Crypto API 计算，和 shasum -a 256 结果一致。

颜色格式转换

HEX、RGB、HSL 互相换算，实时预览。

文本统计

字数、行数、UTF-8 字节数，边打边算。
