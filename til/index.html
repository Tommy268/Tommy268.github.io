用 ssh -L 把远程端口搬到本地

2026-10-24

服务器上起了个调试用的服务，不想为它开防火墙端口，就在本地直接看。

ssh -N -L 8080:localhost:8000 me@server
# 然后本地访问 http://localhost:8080

用在：远程调试 Web 服务、连只监听 127.0.0.1 的数据库。加 -N 表示只转发、不开 shell。

找出是哪次提交动了这行代码

2026-10-22

接手一个老项目，某行代码看起来莫名其妙，想知道当初为什么这么写。

git log -S"超时时间" --oneline -- path/to/file.py
git log -L 120,140:path/to/file.py

用在：查某段逻辑的来历。-S 按内容差异搜，-L 直接看某几行的演变历史。

一行命令临时起个静态服务

2026-10-20

页面里用了 /style.css 这种根路径，直接双击打开会丢样式，必须走 http。

python -m http.server 8000
python -m http.server 8000 --directory ./public

用在：本地预览静态站、给同事临时分享一个目录（记得别在公网机器上随便开）。

du -sh 找出是谁把磁盘吃光了

2026-10-17

磁盘莫名其妙 100%，第一件事是按目录大小排序。

du -sh ./* 2>/dev/null | sort -h | tail -10
du -h -d 1 . | sort -h | tail

用在：清理 pip / npm / docker 缓存。我遇到最多的是 ~/.cache 和 docker 的 overlay 目录。

curl 只看响应头和耗时

2026-10-14

排查线上接口慢，开浏览器太重，直接看响应头更快。

curl -I https://example.com
curl -o /dev/null -s -w '%{http_code}  %{time_total}s\n' https://example.com

用在：确认状态码、看缓存头、量一次请求到底花了几秒。-I 只发 HEAD。

SQLite 用 EXPLAIN QUERY PLAN 看有没有全表扫描

2026-10-11

表到了几万行之后查询突然变慢，先确认是不是没走索引。

EXPLAIN QUERY PLAN
SELECT * FROM messages WHERE room_id = 1 ORDER BY id DESC LIMIT 50;

CREATE INDEX idx_messages_room_id_id ON messages(room_id, id DESC);

用在：输出里出现 SCAN 就是全表扫，出现 SEARCH ... USING INDEX 才是走了索引。复合索引的列顺序要和查询条件、排序一致。
